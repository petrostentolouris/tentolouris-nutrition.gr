- style.css: στυλ · app.js: υπολογιστής, κύκλος υπηρεσιών, κουμπί «επάνω»
- *.webp, world.svg: εικόνες · og-image*.jpg: εικόνα κοινοποίησης (Viber, Messenger, Facebook)
- gfs-didot.woff, manrope.woff: γραμματοσειρές, φιλοξενούνται εδώ (άδεια OFL, βλ. LICENSE-*.txt), χωρίς σύνδεση στη Google
- CNAME: το domain για το GitHub Pages · sitemap.xml, robots.txt: για τη Google
- Κάθε σελίδα έχει δικό της τίτλο, περιγραφή, canonical, hreflang (ελληνικά ↔ αγγλικά) και δομημένα δεδομένα schema.org (Person, ProfessionalService, FAQPage).
